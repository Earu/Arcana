Prototypes and abandoned experiments. Nothing here is loaded by the addon, and nothing in
`lua/` references it. Kept so the same ground is not re-explored.

| Folder | Status | Summary |
| --- | --- | --- |
| [gpu_particles/](gpu_particles/) | Abandoned | GMod's particle system on the GPU with custom Source shaders. No win over the CPU path, visuals could not be matched 1:1. |
| [spell_fusion/](spell_fusion/) | Proof of concept | Runnable fusion spells generated from two parents via the Claude API. Works, not shipped. |
| [weapon_classification/](weapon_classification/) | Proof of concept | Static hitscan / projectile / irrelevant classification of any SWEP, plus a labelled dataset. |
